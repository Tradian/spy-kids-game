# Little Agents — Spymaster Voiceover Script

One voice throughout (the Spymaster): warm, playful, a little conspiratorial,
never sarcastic at the child. Pace slow-ish; these ears are 4–6 years old.

Asset key → file name convention: `<key>` → `assets/vo/<key>.mp3`.

> **Scroll Room guardrails:** verse texts below default to the Tree of Life
> Version and say “the LORD” / “Adonai” for the divine name. **Ian approves
> every scroll message script and all Hebrew pronunciation before anything
> is bundled** — AI Hebrew is inconsistent; a human re-record may beat the
> pipeline here (spec §6).
